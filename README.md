# Chaos Pendulum

An interactive double pendulum simulation with a real-time physics dashboard.

Reengineered as a production-grade **Next.js 15 + TypeScript** application per
the plan in [`agents/AGENTS.v2.md`](agents/AGENTS.v2.md). The original
self-contained `index.html` is preserved in the repo root as the golden
differential-testing oracle.

## Getting Started

```bash
npm install
npm run dev        # develop at http://localhost:3000
npm run build      # production build
npm run start      # serve the production build
```

## Testing

```bash
npm run test       # Vitest unit + component + a11y (jest-axe)
npm run test:e2e   # Playwright E2E (builds first, then tests)
npm run typecheck  # tsc --noEmit (strict)
npm run lint       # ESLint + "use client" guard for styled-components files
npm run verify     # typecheck + lint + test + build
```

Golden physics values are generated by `scripts/generate-goldens.mjs`
(a verbatim copy of the original simulation's math) and asserted in
`src/physics/physics.test.ts` together with a bit-exact differential test
against `src/tests/oracle.ts`.

## Architecture

```
chaos-pendulum/
├── index.html                  ← original simulation (golden oracle, kept as-is)
├── agents/AGENTS.md            ← v1 reengineering plan (superseded)
├── agents/AGENTS.v2.md         ← executed plan (this rebuild)
└── src/
    ├── app/                    ← App Router layout + page (SSR via registry)
    ├── lib/                    ← theme tokens, ThemeProvider, GlobalStyle, registry
    ├── components/             ← Slider, Toggle, Button, ColorSwatchGroup,
    │                             ModeSwitch, LiveReadout, Sidebar, CanvasStage,
    │                             Dashboard (all WCAG 2.1 AA, native elements)
    ├── physics/                ← Lagrangian equations + RK4, workerCore,
    │                             Web Worker (transferable Float32Array batches)
    ├── renderers/              ← IRenderer contract, TrailBuffer ring,
    │                             Canvas2DRenderer, ThreeRenderer (dynamic import)
    ├── hooks/                  ← usePhysics (stable API + throttled stats)
    └── tests/                  ← differential oracle + Playwright E2E
```

Key decisions (details in the plan):

- **Physics off the main thread** — RK4 runs in a dedicated Web Worker;
  state streams to renderers as transferable `Float32Array` batches
  (every step included, so trails never miss points at high speed).
- **`IRenderer` contract with mandatory `dispose()`** — the 2D↔3D swap
  leaks nothing; the Three.js path tears down geometries, materials,
  controls and the WebGL context itself.
- **styled-components (SWC) as the only styling paradigm** — CSS custom
  properties carry the design tokens; no Sass, no Babel.
- **Float32Array circular trail buffer** — replaces `Array.shift()`.

## Features

- **Real-time physics controls**: gravity, masses, arm lengths, initial angles
- **RK4 integration**: 4th-order Runge-Kutta, fixed timestep dt = 0.15
  (behavior-parity with the original)
- **Trail rendering**: configurable length and color
- **Ghost pendulums**: visualize chaotic divergence from nearly identical
  starting conditions
- **Speed multiplier**: up to 10× simulation speed
- **Live state readout**: current angles and angular velocities
- **2D and 3D renderers**: Canvas 2D and Three.js (OrbitControls) views —
  both zoom with the mouse wheel; 2D resets zoom on double-click
- **Dark/light theme**: system-aware with explicit override, persisted
- **Accessibility**: WCAG 2.1 AA — native form elements, keyboard-operable
  color swatches and switches, visible focus indicators

## Physics

Models a double pendulum using the full Lagrangian equations of motion:

```
α₁ = [ -g(2m₁+m₂)sin(θ₁) - m₂g·sin(θ₁-2θ₂)
         - 2sin(θ₁-θ₂)·m₂(ω₂²l₂ + ω₁²l₁·cos(θ₁-θ₂)) ]
      / [ l₁(2m₁+m₂ - m₂·cos(2(θ₁-θ₂))) ]

α₂ = [ 2sin(θ₁-θ₂)(ω₁²l₁(m₁+m₂) + g(m₁+m₂)cos(θ₁)
         + ω₂²l₂m₂·cos(θ₁-θ₂)) ]
      / [ l₂(2m₁+m₂ - m₂·cos(2(θ₁-θ₂))) ]
```

Integration uses **4th-order Runge-Kutta (RK4)** with a fixed timestep of
dt = 0.15 — intentional parity with the original, verified by
bit-exact differential tests.

## Controls

| Control | Description |
|---|---|
| Gravity g | Simulation gravity strength (0.01 – 0.5) |
| Mass 1 / 2 | Bob masses — affect dynamics and rendered size |
| Arm 1 / 2 | Arm lengths as fraction of canvas size |
| Angle 1 / 2 | Initial angles (applied after Reset) |
| Renderer | 2D (Canvas) or 3D (Three.js + orbit camera) |
| Wheel | Zoom the view (both renderers); double-click resets 2D zoom |
| Trail length | How many points the trail retains (20 – 800) |
| Speed | Simulation steps per frame (1× – 10×) |
| Trail color | 7 preset colors |
| Ghost pendulums | Launch 6 near-identical pendulums to show chaos |
| Theme | System-aware dark/light with persisted override |
